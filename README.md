এখানে এখনো Supabase বা আসল ডেটা নেই; সেটা Stage 1-এ আসবে।

## আইফোন থেকে GitHub-এ আপলোড (ধাপে ধাপে)
1. সাফারিতে **github.com** খুলে লগইন করুন।
2. নিচে ডানে ঘরের আইকন বা উপরে **+** চেপে **New repository** বেছে নাম দিন `zilax`, **Public** রাখুন, **Create repository** চাপুন।
3. নতুন রিপোজিটরিতে **uploading an existing file** (বা Add file → Upload files) চাপুন।
4. **choose your files** চেপে Files অ্যাপ থেকে **সব ফাইল একসাথে** সিলেক্ট করুন (ফোল্ডার নয়, ফাইল; ফাইলগুলো সব একই স্তরে থাকবে)।
5. নিচে **Commit changes** চাপুন।
6. **Settings → Pages** খুলুন। **Source:** *Deploy from a branch*, **Branch:** `main` এবং `/ (root)` বেছে **Save** চাপুন।
7. ১–২ মিনিট পর উপরে লিংক আসবে, সাধারণত `https://আপনার-ইউজারনেম.github.io/zilax/`। সেটি সাফারিতে খুলুন।

> আপনার পুরোনো Zilax সাইট যেখানে আছে সেখানে সরাসরি ফাইল না তুলে নতুন `zilax` রিপোজিটরিতে তোলাই নিরাপদ। পছন্দ হলে পরে পুরোনোটা বদলাবেন।

## জানা সীমাবদ্ধতা (Stage 0)
- ছবিগুলো রেফারেন্স স্ক্রিনশট থেকে নেওয়া, লেখা মুছে। কাচ্চি বিরিয়ানি ও লন কুর্তির ছবি নেই (ইমোজি বসানো)। Stage 2-এ সুপার অ্যাডমিন থেকে সব ছবি বদলানো যাবে।
- কার্ট ও স্টক আউট শুধু আপনার ফোনের ব্রাউজারে মনে থাকে। সবার জন্য আসল ডেটা Stage 1 থেকে।
- লগইন, অর্ডার, পেমেন্ট এখনো কাজ করে না, এগুলো পরের Stage-এ।
